### **5. The shebang-free execution principle**

Use explicit interpreter dispatch rather than assuming the operating system knows how to execute an arbitrary source file.

For example:

```
python3 program.py
node program.js
bun program.ts
deno run program.ts
ruby program.rb
php program.php
pwsh -File program.ps1
bash program.sh
cargo run --manifest-path Cargo.toml
```

The universal launcher resolves the runtime, checks its availability, measures execution limits, and invokes the correct adapter.
