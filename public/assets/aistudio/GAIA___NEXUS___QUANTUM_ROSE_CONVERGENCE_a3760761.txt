# 1. GOVERNING INVARIANT

Implement one shared authorization contract:

`A = B && C && V`

Where:

- B = boundary admissibility.
- C = measured computational capacity.
- V = independent verification.
- A = authorization to commit or execute the requested operation.

Missing, stale, false, or unknown conditions must withhold authorization.

Maintain separate internal observability for B, C, and V. Never collapse unknown into true.

The governing doctrine:

- Time establishes the execution boundary.
- Measurement establishes computational capacity.
- Verification establishes correctness.

The visual governor cannot override this invariant.
